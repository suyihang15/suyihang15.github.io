编译自己的操作系统（基于Linux）

注：本文主要介绍如何基于Linux的内核编译一个最简单的操作系统，编译Linux内核+BusyBox，制作可启动迷你Linux系统

1、环境准备

wsl –install（在windows安装Linux的环境）

2、编译步骤

一、更换国内软件源（解决下载慢）

备份原有软件源

sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak  

作用：备份系统默认源，后续出错可以恢复

写入阿里云高速镜像源

sudo tee /etc/apt/sources.list > /dev/null << ‘EOF’
deb http://mirrors.aliyun.com/ubuntu/ jammy main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-security main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-backports main restricted universe multiverse
EOF  

作用：替换国外源，大幅加快软件下载速度

更新软件仓库

sudo apt update

sudo apt upgrade -y  

作用：刷新源缓存，升级系统基础软件

二、安装全套编译依赖环境

sudo apt install -y gcc make flex bison libncurses-dev cpio xorriso grub-common grub-pc-bin grub-efi-amd64-bin libelf-dev libssl-dev bc wget qemu-system-x86  

作用介绍

  •  gcc/make ：C语言编译工具

  •  flex/bison ：内核语法编译依赖

  •  libncurses-dev ：图形配置界面依赖

  •  cpio/xorriso ：打包文件、制作ISO镜像

  •  grub系列 ：系统引导必备工具

  •  qemu-system-x86 ：虚拟机运行自制系统

三、创建专属编译工作目录

mkdir -p ~/mini_os

cd ~/mini_os  

作用：统一存放源码、编译文件，路径干净无权限冲突

四、编译Linux原生内核

下载Linux内核源码（阿里云镜像）

wget https://mirrors.aliyun.com/linux-kernel/v6.x/linux-6.1.tar.xz  

解压内核源码

tar -xf linux-6.1.tar.xz  

进入内核源码目录

cd linux-6.1  

生成内核默认配置

make defconfig  

作用：自动生成通用电脑适配内核配置，新手无需手动修改

多核全速编译内核

make -j$(nproc)  

作用：调用电脑全部CPU核心编译，提升编译速度
编译完成产物： arch/x86_64/boot/bzImage  内核镜像

返回上级目录

cd ..  

五、编译BusyBox极简命令工具箱

BusyBox集成ls、cd、mkdir等所有Linux基础命令

下载BusyBox源码

wget https://busybox.net/downloads/busybox-1.36.1.tar.bz2  

解压源码

sudo apt install -y bzip2（下载解压软件）

tar -xf busybox-1.36.1.tar.bz2  

进入BusyBox目录

cd busybox-1.36.1  

生成默认配置

make defconfig

开启静态编译（核心关键）

sed -i ‘/CONFIG_STATIC=/d’ .config
echo “CONFIG_STATIC=y” >> .config  

作用：编译成独立静态程序，不依赖系统动态库，迷你系统可直接运行

多核编译BusyBox

make -j$(nproc)  

安装编译好的命令工具

make install  

作用：命令全部输出到 _install 目录，作为系统基础命令集

返回上级目录

cd ..  

六、搭建迷你Linux根文件系统

创建根文件系统文件夹

mkdir rootfs  

拷贝BusyBox所有命令到根系统

cp -r busybox-1.36.1/_install/* rootfs/  

创建系统必备空目录

mkdir -p rootfs/{dev,proc,sys,etc}  

作用：dev设备目录、proc系统信息目录、sys硬件目录

创建系统必要设备文件

sudo mknod rootfs/dev/console c 5 1
sudo mknod rootfs/dev/null c 1 3  

作用：控制台终端、空设备，系统启动必需

配置系统开机自动启动终端

echo ‘::askfirst:-/bin/sh’ > rootfs/etc/inittab  

作用：系统开机直接进入命令行终端

七、打包内核内存文件系统

进入根文件系统目录

cd rootfs  

打包压缩为initramfs启动文件

find . | cpio -o -H newc | gzip > ../initramfs.cpio.gz  

作用：把整个根系统打包，让内核启动时加载

返回上级目录

cd ..  

八、制作GRUB引导启动ISO镜像

创建ISO镜像目录结构

mkdir -p iso/boot/grub  

拷贝内核与启动文件到ISO目录

cp linux-6.1/arch/x86_64/boot/bzImage iso/
cp initramfs.cpio.gz iso/  

编写GRUB系统启动菜单

cat > iso/boot/grub/grub.cfg << ‘EOF’
menuentry “My Self Linux” {
linux /bzImage
initrd /initramfs.cpio.gz
}
EOF  

作用：虚拟机启动时显示系统选项，指定内核与根文件系统

生成最终可启动ISO镜像

grub-mkrescue -o mylinux.iso iso  

生成文件： mylinux.iso  自制完整Linux系统镜像

其是可以直接安装在虚拟机上的

总结：其用Linux搭建操作系统本身不难，因为已经用很成熟的内核这些了，但本身还是调用别人的东西，希望后面有人能完整的搞出完整的独立操作系统吧。

nas自动化影片思路

注：本文章主要提供思路和搭建方法

1、准备情况

（1）Docker（用于部署环境）

（2）nastool（用于管理资源的爬取和下载情况）

（2）jackeet（用于收集种子库）

（3）QBittorrent（用于下载资源）

(4)TMDB的Key（用于刮削的准确性，当然你自己有刮削就不管）

2、部署（本人是飞牛的nas，其他家的根据具体文件调整）

部署的compose

启动

docker-compose up -d

3、调整

Nastools

访问界面IP:3000

账号admin

密码password

登录界面

Jackett

访问界面IP:9117

这里你要根据自己的情况添加种子站点，如果没有私有的站点账号，就选择好几个公开的站点就行，如果有不能用的会自动删除的，然后添加好后，复制密钥，粘贴到nastool的设置里的索引器jackeet里测试，成功就行了。

QBittorrent

访问界面IP:8088

账号：admin

密码：在docker容器的日志里查看，登录后查看

记得在nastool的设置下载器里面的Qbittorrent也设置好，IP地址和账号密码搞好了，再测试一下，确定就链接好了。

可以设置一下TMDB那个，可以免费申请的，然后，注意其他的在nastool设置一下，比如做种时间，上传速度这些，不然会被认为的在跑PCDN的。

之后就看你需求更改就行

4、自动化思路

nastool用于进行整体的管理，jackett作为种子的搜集器，QBittorrent作为下载器，下载到本地，TMDB的key帮助刮削准确性就很高了。

总结：自动化的方法其实还有很多，比如我之前说的RSS订阅，主要是看你怎么折腾，网上的方法教程还是很多的。

关于PT

注：本文章只介绍PT，请不要轻易相信那些什么拉人什么的

PT全称是 Private Tracker（私有种子服务器），本质上是一个封闭、半封闭的种子分享社区。

和你平时用的迅雷、百度网盘、公开BT站有很大不同，个人理解就是那些私人的种子网站，相比于公开BT/网盘 这些PT站的公开BT站的资源虽然多，但鱼龙混杂，同一部电影，可能同时存在枪版、低码率、带水印、甚至被植入病毒的版本；网盘下载虽然方便，但热门资源秒传、冷门资源几乎绝迹，而且随时面临版权风险和限速的困扰。而PT站则通过严格的准入和审核机制，从根源上解决了这些问题，基本上在那个社区的都有跑的任务，不会有死种，而且基本上所有的用户都要维护，不然就封号，资源真的很好，这种高质量的体验，也意味着更高的门槛和更严格的规则。公开下载的核心是“索取”，而PT的核心是“分享”。你享受了别人提供的稳定高速下载，就有义务为后来的人提供上传，这种“我为人人，人人为我”的信用体系，才是PT社区能长久运转下去的根基。

关于PT说的

  • 保种：把下载好的资源挂在服务器/NAS上，持续为其他用户上传。保种越久，社区越活跃，你的账号也越安全。

  • 分享率（Ratio）：上传量 ÷ 下载量，大部分PT站要求 ≥1.0，也就是“下多少，传多少”。

  • 魔力值/积分：部分PT站的虚拟货币，可以用来换邀请码、免考核、或者兑换下载券，是“老玩家福利”。

  • 考核期：新用户注册后，需要在规定时间内（比如30天）完成指定的上传量/分享率要求，不达标会被封号。

  • 邀请码：PT站的“入场券”，老用户才能发，你违规被封，邀请你的人也会被牵连，所以没人会随便给陌生人发码。

  • HDSky（天空）：国内最热门的高清PT站之一，资源全、用户多，也是很多新手的目标站。

  • 星码（带星星的邀请码）：HDSky里的高级邀请码，只有站内高等级用户（VIP/老用户）才有资格发，注册后直接跳过考核期，账号更稳，圈内俗称“星码”。

HDSky像这种都有一定的门槛，一般其注册都很少而且是在节假日才开放，开放时间很短，一般要内部人员推送才行，而且进去了还有上传的任务，不然很快号就没了，所以，一般不要轻信那些什么卖号的。

总结：相比于BT其PT资源跟好，但是门槛跟高。

steam假入库

注：本文章主要讲解steam假入库的原理和风险。

1、原理

Steam 是本地+云端双重验证的方式：

1. 云端：账号绑定的 License（许可证），官方数据库记录。
2. 本地：-  Steam\steamapps\appmanifest_.acf （清单文件）

  •  Steam\config\config.vdf （下载密钥）

  • Steam 客户端启动时优先读本地缓存 → 有就显示“已拥有”

假入库核心逻辑：不上传云端，在本地骗过客户端然后让他认为你电脑上有了这个游戏。

1、伪造 appmanifest（最基础）

  • 手动/脚本生成  appmanifest_12345.acf 

  • 写入  steamapps  文件夹

  • Steam 刷新库 → 直接显示已安装/已拥有

  • 缺点：不能下载，只能骗库显示

2、DLL 劫持（hid.dll / steam_api.dll）

  • 替换 Steam 目录下  hid.dll  或注入  steam_api64.dll 

  • 拦截 Steam 验证请求，返回“已授权”假结果

  • 可正常下载、玩单机

  • 风险最高：红信、盗号、木马

3、PowerShell 脚本一键执行（现在最常见）

一般就是（网上几块钱卖的基本上是这玩意）

irm steam.work | iex  

1、从陌生网站下载脚本/恶意程序

2、自动：- 关 Defender / 加排除

3、改注册表

4、替换 DLL

5、写入假 manifest

6、全程管理员权限，电脑完全敞开

一般情况下，不太建议这么搞，因为其本身是下载第三方的脚本文件，不知道其有没有被植入后门或者病毒。

对于假入库也有不少工具，但是这里也不建议，因为有红锁的风险。

2、关于D加密

有的人在找破解资源的时候，可能会有什么开启虚拟化的过程。

其本质是关闭电脑上所有的验证，让其不能验证，就可以绕开了，但是本身还是和上面的原理差不多的，而且搞那些虚拟化有被病毒感染的风险和电脑性能会有损耗，

3、防范

一般不要下来历不明的软件和买cdk时，如果要你干什么cmd输命令的都是假的，一般是会直接给激活码然后激活就行，不要贪便宜，还有一些是礼物发货，这个有被收回的风险。

总结：反正一般不贪便宜基本上问题不大。

一般不要下来历不明的软件和买cdk时，如果要你干什么cmd输命令的都是假的，一般是会直接给激活码然后激活就行，不要贪便宜，还有一些是礼物发货，这个有被收回的风险。

总结：反正一般不贪便宜基本上问题不大。

系统还原

注：本文章主要介绍网吧的开机后系统还原的原理。

主流的还原方法一般就两种（硬件和软件方便的）

还原软件（冰点还原）

硬件还原卡

一、最主流：冰点还原（Deep Freeze）
原理：

把 C 盘（系统盘）做成只读镜像，你下载东西、装软件、中毒、乱改系统，全部存在临时虚拟缓存里

一重启，缓存直接清空，C盘一秒变回老板设定的纯净状态，D盘游戏盘不还原，游戏、下载的东西一直保留

一般情况是

 先装好纯净 Windows、驱动、运行库、游戏环境，调好桌面、壁纸、浏览器、关闭系统更新，安装冰点，只保护C盘，D盘不保护，设置密码，普通用户关不掉，开机默认冻结模式 → 重启必还原

管理员一般是（更新用）

快捷键： Ctrl + Alt + Shift + F6 （记得好像是这个）
输入密码，切换解冻模式
更新游戏、系统、软件，改完切回冻结，重启保存新状态。

二、老网吧：硬件还原卡（小哨兵、海光、蓝沙）

很早以前网吧用，PCI 小卡片插主板上。

硬件接管硬盘，比软件更底层

所有修改都存在内存/临时空间，重启清空

现在基本淘汰，因为维护麻烦、不能远程更新游戏

三、还有一种：易乐游 / 迅闪（网吧无盘系统）感觉现在基本上都是这个吧网吧

大型连锁网吧用无盘系统：
电脑本身没硬盘，系统从服务器读取，
所有电脑共用服务器镜像，重启自动还原，一台服务器统一更新。

无盘系统是很方便的

总结：这差不多就是网吧电脑比家用电脑快很多的原因，但是如果是你自己的电脑我是很不建议这么搞的，虽然确实这样会很快，但是基本上数据这些不太好存储，而且，其本身家用搞的基本上是跑在软件层面的，问题风险这些是不太可控的。
