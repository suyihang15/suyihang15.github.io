wordpress主题分享

注：这是本人自己弄的wordpress，用的MIT协议，很宽松的，希望这都不要没人遵守，然后有些基础功能，已在Github上开源，然后基础的文件里面也些清楚了。

项目地址：suyihang15/suyihang15-blong-theme: 一款简约风的wordpress个人博客主题

下载地址：https://github.com/suyihang15/suyihang15-blong-theme/releases/download/1.0.0/suyihang15-blong-theme.zip

1、特性

简洁现代的设计风格

响应式布局，支持移动端

可视化自定义设置，但就一些基础的（无需代码修改）

2、功能

支持社交链接、个人简介展示

打赏功能，支持二维码上传

自定义颜色主题

支持评论、RSS 订阅（本人觉得RSS这的很好用）

安装主题后，在 WordPress 后台的 **外观 > 自定义** 中可以进行以下设置：

QQ 号码 微信号 微信链接 B 站主页链接 GitHub 链接这些展示

ICP 备案号和公安备案号，不然用国内服务器还是比较麻烦的。

自定义首页顶部横幅文本（支持简单 HTML）

首页封面图片

网站背景图片

简介标题、角色简介、个人简介

所在地、工作经验、技术栈

微信打赏二维码（上传图片）

支付宝打赏二维码（上传图片）

打赏说明文本，主要打赏方式就是二维码。

主色调 背景色 文字颜色设置

主题支持自定义菜单。在 **外观 > 菜单** 中创建菜单并分配到“Primary Menu”位置。

文章支持特色图片。在编辑文章时设置特色图片即可。

_3、_许可证

MIT License

_4、_作者

suyihang15

请遵守本人的开源协议，然后也不做过多的限制。

5、安装

下载好上面的文件后，去wordpress的外观主题，安装主题里选择提供的安装包就行。

想不到好的封面了，就这样吧。

6、思路及文件大致介绍。

README.md：就是你现在看的这个文件，介绍主题怎么用、有什么功能。

style.css：主题的“衣服”，决定网站看起来是什么样子，比如颜色、字体、布局等。

functions.php：主题的“大脑”，里面写了很多代码，让主题能做各种事情，比如添加菜单、自定义设置、加载脚本等。

index.php：首页的模板文件，负责显示博客的文章列表。

front-page.php：首页模板文件，适用于设置为静态首页时，显示个人简介和文章列表。

home.php：文章列表页模板，用于博客页面或“最新文章”页面。

single.php：单篇文章页面的模板，打开一篇文章时用的。

page.php：独立页面的模板，比如“关于我”“联系我”这样的页面。

header.php：每个页面的顶部部分，包含网站标题、导航菜单、搜索框和社交链接等。

footer.php：每个页面的底部部分，包含版权信息、备案号、RSS 链接等。

comments.php：评论区的模板，显示评论列表和评论表单。

searchform.php：搜索框的模板，用户搜索文章时使用。

assets/js/load-more.js：前端脚本，支持“加载更多文章”的 AJAX 加载功能。

template-parts/：模板部件文件夹，存放可复用的页面片段。

 template-parts/content-post.php：文章列表中每一篇文章卡片的显示内容模板。

 template-parts/homepage-profile.php：首页个人简介区块模板，显示封面图片、简介文字、个人信息。

template-parts/post-list.php：文章列表区块模板，统一处理文章循环和“加载更多”按钮。

inc/customizer.php：自定义面板配置文件，定义外观 > 自定义中的设置项。

具体的就看你自己了，根据自己需求来改吧，代码也不多的。

7、效果和功能展示

大致就这样提供了一些基础的自定义功能，太多了不想写了，但是基本上就够了，根据需求来吧。

总结：本人已经放了安装的所有东西，然后请自行发挥，但请遵守开源协议，如果还需要什么功能或者要改什么，请留言或者在本人GitHub仓库去提，帮我更改，谢谢。

wordpress制作主题开发（基础开发）

注：在学习之前，你要有一些php，html，css，js的基础，我的教程主要是本地写好了，再上传，主要是帮助你可视化去的调整你的模板。

1、准备条件

（1）WordPress的源码（这是一切的开始）

（2）vs code（用于写一些基础文件的代码）

（3）小皮面板（当我们代码写完了，就要去看样子是什么样子的）

2、环境配置

（1）一键启动

这样配置好数据库和web，如果没有下载my sql请自行下载

（2）网站配置

域名自己写，其是在本地的，所以随便添加都行，这里的根目录，就选择好解压后的文件，之后启动，打开网站就可以看到创建的网站了，其是在本地的。

这是大致的样子，就和我们最开始在服务器上创建wordpress一样，配置好数据库就行了。

请自行创建数据库，创建好了，就和我们在服务器上的一样

（3）编写代码

用vs code打开项目源码，这里就可以开始编写了。

（4）简单介绍(一般要改主题碰这几个就行，其他的系统文件建议不要改)

style.css

让 WordPress 识别这是一个主题（顶部固定注释）
整站所有样式：颜色、布局、字体、边距、排版，全都写在这里。

functions.php

主题的功能配置中心。
在这里加功能：注册导航菜单、开文章缩略图、引入自己的CSS/JS、加自定义小功能，所有自定义代码都放这，不改系统核心文件。

header.php

网站顶部通用模板。
每个页面都会加载它，放网页头部、logo、导航栏、网页头部meta信息。

footer.php

网站底部通用模板。
所有页面共用，放版权信息、底部文字、加载js代码。

index.php

主题默认首页/兜底模板。
没单独做模板的页面，都用它显示，用来布局首页、文章列表。

single.php

专门管 文章详情页。
点开一篇文章，页面长什么样、内容怎么排，都改这个。

page.php

专门管 独立页面（关于我们、联系我们这种单独页面）。

archive.php

分类页、标签页、文章归档列表页，都由这个文件控制布局。

404.php

网址不存在、打不开的时候，显示的404页面，自己可以改文案和样式。

一般情况我们是搞wordpress\wp-content\themes这里的文件，这是里面的主题，其本身就有一些，我们写的时候可以参考一下，可以省很多事情，我个人觉得研究这一个基本上就够了，其他的，看不懂就不要碰。

就是这个，这里我创建了一个123的文件夹，里面有style.css和index.php，所以在这个主题里就可以看见,但是我是没有任何内容的我们要自己更改。

创建文件的结构大概是

themes/一个文件夹（我这里命名的是123）
├── style.css
├── index.php
├── functions.php
├── header.php
├── footer.php
├── single.php
├── page.php
├── archive.php
├── 404.php
├── comments.php
├── sidebar.php
│
├── assets/
│ ├── css/
│ ├── js/
│ └── images/
│
├── template-parts/
└── inc/

这个是我用的他们的主题的大致的结构

这个应该都可以看懂吧，所以我说你得有一定的一些基础才能去手搓一个模板，不然就老老实实的用人家自带的吧，其可以改的东西还是很多的，或者参考别人现成的去改，但是，请保留原作者的信息，毕竟从0开始写真的很困难，记住不要重复造轮子。

使用

当你全部手搓完成以后，做成压缩包就可以让其他人用了

就是后面如果要部署改项目，就上传压缩包到服务器，然后解压缩，就和前面部署这个wordpress项目一样，就可以看见你改好的东西了。

总结：这个教程主要是教你怎么去做一个大致的模板，具体你要怎么改还是要根据你的需要去搞，本人主要是搞python的，php这些就会一些基础，如果你真正要去完美的搞一个主题那么要做的是很多的。

图床的搭建和使用

注：我确实觉得这个很适合那些刚开始想网站小白要展示一些照片，但是又觉得存储不太方便的人。

1、什么是图床

按照我个人的理解，他就是一个可以帮我们存储图片的软件，当我们想要去使用时，只需要调用它的URL（就是他的一个专属地址）就行。

2、搭建图床（空蓝图床其本身是开源的）

首先你要有一台云服务器（建议香港的，如果是国内的记得备案）

（1）安装宝塔面板

if [ -f /usr/bin/curl ];then curl -sSO https://download.bt.cn/install/install\_panel.sh;else wget -O install_panel.sh https://download.bt.cn/install/install\_panel.sh;fi;bash install_panel.sh ed8484bec

（2）下载这个压缩包

https://github.com/lsky-org/lsky-pro/releases/download/2.1/lsky-pro-2.1.zip

（3）添加站点

安装好php8.1，其他版本可能会出错，我个人搞得是这个。

创建站点，记得要添加my sql数据库，用于做存储，不然他就是一个静态文件，并填好域名后面要解析。

打开文件目录并上传之前下载的安装包解压

设置网站的运行目录为public

设置伪静态

代码

location / {
if (!-e $request_filename) {
rewrite ^(.*)$ /index.php?s=$1 last; break;
}
}

保存好了，然后就访问解析好的域名就行了

如果有上面的错误，根据上面要的，安装对应的插件

注意有部分可能被禁用了，设置一下就行

一个一个设置好了就可以开始了

这里填入你前面设置的数据库名称和密码，其他的不要动，数据库类型选择你前面安装的版本看一下就行。

登录以后上传就行

上传后你会得到一个URL后面直接调用就行，很方便的

这个图床的其本身是开源的，网络上也有不少基于他搭建的免费图床，你可以自己搭建，也可用别人搭建好的，总之是很方便的。

一个简单的调用方法就是

< img src=”图片的URL”>

我个人觉得是很方便的

总结：如果你的网站有挂图片的需求这会是一个不错的选择，但是切记，不可用来存储任何暴力色情的图片，其照片的URL是任何人都可以用的，注意不要上传太过私密的照片。

异地组网（tailscale）

注：因为本人之前尝试了frpc穿透家里的设备想要试试异地组网访问家里的设备，而且不要钱，就写了这个。

1、准备（个人是很推荐tailscale）

安装好tailscale软件就行其基本上支持市面上绝大多数设备。

2、为什么玩异地组网。

我们知道，一般我们玩nas这些的，都需要开通公网IP还要配置好一些列乱七八糟的配置，用这个软件我们就可以实现外部设备和家里的网络处于同一局域网下。

3、怎么搞

需要组网的设备下载好这个软件

注册号一个账号在网站Tailscale

在下载号软件的设备上登录你的账号就行了，你们就在同一局域网下了

没错就这么简单，都登录以后，你就可以在官网登录看到所有信息了

比如，这里的第一个是我的nas设备，后面那一串IP就是我nas的管理后台，其次这里还可以设置流量的进出口的流量都可以设置的。

组好后就像我这样就可以连接好设备了，整体网速还行，挺舒服的，主要是操作简单没有过多复杂的设置，而且不会破坏你原来的网络配置，你就相当于连接上了家里的网。

总结：这种方式还是很香的，没有复杂的操作，而且不要钱。
