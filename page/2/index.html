关于树莓派

注：这是本人最近玩树莓派的一些心得，本人算是第一此玩，我个人买的是树莓派zero w带WiFi的，可能没有那么专业，如有错误请请大佬指正。个人建议买一个HDMI mini转HDMI的转换器和usb转的扩展坞（最好是带网口的），方便插鼠标这些，虽然知道IP地址就可以访问，但是还是建议可以买一个。

1、关于我的理解

我个人认为他就是一个低功耗的小电脑。

缺点就是，他大部分是ARM架构的，本来是想买x86架构的，但是基本上没有，所以，我觉得想玩x86的就不用折腾树莓派了，虽然架构不算好，毕竟个人觉得x86架构的比ARM的使用体验会好的多，毕竟软件支持的要多一点，

优点首先他功耗真的很低，本人可以用它来执行一些小任务，而且稳定性很好，毕竟装的是Linux系统，然后扩展功能也很强，但是要求有一定的动手能力，本人只知道焊一点洞洞板，所以请人代工的，还加了针脚方便扩展，然后，我觉得他可以帮助我学习一些Linux指令，所以，对于想学习Linux系统的还是很推荐的，是个不错的入门方法，而且本身很便宜，买一些性能比较差的就行，毕竟一般不可能有树莓派连ssh都用不了的。

2、当你选好以后，就开始是刷系统了，个人推荐Raspberry pi os

下载树莓派烧录工具，选择好对应的就行

一步一步根据这些来，写入就行了，一般是TF卡吧，建议买一个读卡器。

3、基础设置

这是图形化界面，一般第一次玩，我建议全部默认设置。

然后进入桌面，我个人是在这个配置里的全部是打开的，一般开ssh和vnc应该就够了。

然后需要操控的电脑我建议安装

MobaXterm_Personal(用于ssh的GitHub上有汉化的)

realvnc（用于显示桌面图像的）

总结：大概就是这些吧，我个人也是第一次玩，所以感悟就这些，剩下的如docker什么的就自己配吧，本人这个性能很弱，跑docker基本就不要想了，所以，如果有多余的闲钱，可以上好一点的，但是，建议从性能比较弱的开始，便宜，就算坏了也不心疼，还可以试试焊接上其他的东西。

📚 BookReader — 图书管理与阅读器

一款用 Python + PyQt5 编写的桌面端图书管理与阅读器，支持多格式导入、分类管理、阅读进度追踪。本文将详细介绍该程序的设计原理、功能特性、使用方法及技术栈。

🧠 程序原理

整体架构

三层数据流

设计原则

原则 体现
信号-槽解耦 组件间通过 PyQt5 信号通信，不直接调用彼此方法
数据与视图分离 database.py 只管数据 CRUD，UI 层只管展示
解析器策略模式 BaseParser 抽象基类，每种格式一个子类，通过工厂方法获取
线程分离 导入操作在 QThread 中执行，不阻塞主界面
增量迁移 数据库变更通过 ALTER TABLE 兼容已有数据，不丢记录

数据库模型

✨ 功能特性

📥 图书导入

  • 支持 PDF / EPUB / MOBI / AZW3 / TXT / FB2 格式

  • 拖拽文件/文件夹到窗口即可批量导入

  • 自动解析元数据（书名、作者、出版社、ISBN）

  • 自动提取封面（PDF 首页、EPUB 内置封面、TXT 自动生成）

  • 基于文件 MD5 的重复检测，避免重复导入

  • 导入时可选择分类

📂 分类管理

  • 预设 8 个分类：小说、文学、科技、历史、哲学、艺术、教育、其他

  • 左侧栏按分类筛选图书，显示每类数量

  • 支持添加、重命名、删除自定义分类

  • 图书卡片显示分类标签

  • 编辑详情时可修改分类

📚 书架视图

  • 网格视图：卡片式封面展示，鼠标悬停放大效果

  • 列表视图：紧凑列表，适合大量图书浏览

  • 搜索：按书名/作者实时过滤

  • 排序：最近添加、书名 A-Z、作者 A-Z、最近阅读

  • PDF 高清渲染（150 DPI），逐页加载

  • EPUB/TXT HTML 文本渲染，自动分页

  • 三种主题：☀️ 日间 / 🌙 夜间 / 📜 护眼

  • 字体大小自由调节（A+/A- 按钮）

  • 键盘快捷键翻页（← → / A D）

  • 阅读进度自动保存，下次打开继续阅读

📂 项目结构

各模块职责

模块 职责 依赖
database.py 数据库初始化、图书/分类 CRUD、增量迁移 SQLite3
parsers.py 解析各格式图书元数据与内容 PyMuPDF, ebooklib, BS4
utils.py 封面生成、哈希去重、格式判断 Pillow
main_window.py 窗口框架、菜单/工具栏、信号路由 PyQt5
library_widget.py 书架渲染、搜索/排序/分类筛选 PyQt5
reader_widget.py 阅读器渲染、主题/字体切换 PyQt5
import_dialog.py 导入 UI + 后台线程 PyQt5, parsers
detail_dialog.py 图书元数据编辑表单 PyQt5
category_sidebar.py 分类列表展示 + 筛选信号 PyQt5
category_dialog.py 分类增删改管理 PyQt5

🛠️ 技术栈

组件 技术 用途
GUI 框架 PyQt5 窗口、布局、信号槽
PDF 解析 PyMuPDF (fitz) PDF 元数据提取 + 页面渲染
EPUB 解析 ebooklib + BeautifulSoup4 EPUB 元数据 + HTML 内容提取
图像处理 Pillow 封面生成、缩放、格式转换
数据库 SQLite3 图书记录、分类、阅读进度
线程 QThread 导入不阻塞 UI

⚠️ 注意事项

  • 导入时会复制文件到 library/ 目录，原始文件不受影响

  • 删除图书会同时删除 library/ 中的副本和封面缓存

  • MOBI/AZW 格式仅基础元数据支持，建议转为 EPUB 后导入获得完整体验

  • 数据库文件 library.db 和 library/ 目录是核心数据，备份时请保留

  • 分类表中的默认分类可按需修改或删除

效果

🎮 井字棋游戏 (Tic-Tac-Toe)

一个使用 Python 内置 tkinter 库开发的图形化井字棋游戏，支持双人模式和人机对战模式，界面美观、交互流畅。

✨ 功能特性

特性 说明
👫 双人模式 (PvP) 两名玩家在同一台电脑上轮流落子
🤖 人机模式 (PvE) 与 AI 对战，AI 具备智能决策策略
🎨 深色主题 UI 美观的深色界面，X（蓝色）与 O（红色）颜色区分
🏆 获胜高亮 获胜连线自动变为金色，一目了然
🔄 模式随时切换 下拉菜单一键切换模式，自动重置棋盘
🖱️ 纯鼠标操作 点击即落子，无需键盘输入
📦 零依赖 完全基于 Python 内置库，无需安装任何第三方包

🚀 快速开始

  • Python 3.6 或更高版本

  • 操作系统：Windows / macOS / Linux 均可

运行方法

🎯 游戏规则

  1. 棋盘为 3×3 的九宫格，两名玩家轮流落子

🥈 阻挡对手 如果对手下一步能赢，优先阻挡

对于ai

注：本人最近一直在玩ai，主要想说说自己的感受。

我个人是不反对ai的，因为ai确实带给了我很多东西，可以说我学习编程基本上就是靠ai一步一步学着来的，所以我觉得ai是使人进步的，科技本身是不断发展的，我们应该跟上时代，不断地学习才是我们应该做的。

最近也快高考了，我自己是2023年参加高考的，说实话，考的不算好，也没有那么差，虽然只是个二本，但是，我觉得没有什么不好的，起码我还在学习，并没有失败，我觉得这就是大学的意义，不会过多的去约束你，但基本的是要学的，在此之外，你还可以干你喜欢的事情，无论是什么，只要你开心就行。

我很反感的就是那些买课的，也不是说不好，就是感觉他们经常把一些很基础的东西包装的很高大上，教的很多都是网络上免费课程里学的东西，我觉得卖课的更多是教那些我们不付费学不到的东西，而不是教一些网上烂大街的东西。

对于API，我觉得主要是对于那些专业人员或者是尝鲜的人，否则，我不建议任何人去购买，就和前面龙虾热一样，网上一大堆部署的教程都看不懂，花钱代安装，这种就只能被割韭菜，这种就不要妄想能通过ai赚钱了，到哪里都只能是韭菜。

真的，技术永远是第一生产力，这点我觉得到什么时候都不会过时，所以我们无论何时都不要忘记学习，无论是学什么，我不喜欢以高高在上的语气去说任何人，但是事实就是这样，我们在不断发展，我们需要学习，这样才能使我们不掉队。

总结：以上就是我对于ai的看法，以及我胡说的一些东西。

基于python的扫雷

注：这是本人做的小游戏，目的是帮助人学习

项目地址：suyihang15/minesweeper_game: 基于python的扫雷小游戏

成品下载：https://github.com/suyihang15/minesweeper_game/releases/download/1.0.0/minesweeper.exe

扫雷游戏 — 原理与实现

一、游戏概述

扫雷（Minesweeper）是一款经典的单人逻辑推理游戏，核心玩法是在一个隐藏地雷的矩形网格中，通过翻开格子解读数字线索，安全地定位所有地雷。本实现使用 **Python + tkinter** 完整还原经典扫雷的核心机制，并加入了 Chord 双击展开、胜利烟花动画等进阶体验。

二、操作说明

| 左键点击（未翻开） | 翻开格子 |

| 左键点击（已插旗） | 快速解旗，无需右键循环 |

| 左键点击（已翻开数字格） | Chord 双击展开 |

| 右键点击 | 循环切换：无标记 → 旗子 → 问号 |

| 右键点击（游戏开始前） | 允许提前插旗标记（与标准扫雷一致） |

翻开格子显示 数字 (1~8)：表示该格周围 8 个相邻格子中的地雷数。

翻开格子为 **空格**（雷数为 0）：自动递归展开连通空白区域。

翻开格子为 **地雷**：游戏失败，展示所有地雷位置。

旗子和问号标记的格子受到保护，不会被左键意外翻开。

胜利条件

所有非雷格子均被翻开即获胜，无需给每一颗雷插旗。胜利时触发彩色烟花动画。

三、数据结构

board[r][c]    : int    -1 = 地雷， 0~8 = 周围雷数

revealed[r][c] : bool   是否已翻开

flagged[r][c]  : int    0 = 无标记， 1 = 旗子， 2 = 问号

buttons[r][c]  : Button  对应的 tkinter 按钮对象引用

所有数据以二维数组存储，索引 `(r, c)` 对应棋盘坐标。

四、核心算法

4.1 首次点击安全保障

首次点击前地雷尚未布置。玩家点击后：

1. 将该位置及其 3×3 邻域（共最多 9 格）标记为安全区；

2. 从安全区外的所有格子中随机选取 `mines_count` 个放置地雷；

3. 遍历棋盘，计算每个非雷格的周围地雷数。

  • safe_cells = {(safe_row + dr, safe_col + dc) for dr in (-1,0,1) for dc in (-1,0,1)}

  • candidates = [pos for pos in all_cells if pos not in safe_cells]

  • mine_positions = random.sample(candidates, mines_count)

复杂度：O(rows × cols)，在布雷阶段一次性完成。

4.2 周围雷数统计

对每个非雷格子，统计其 8 个方向上的地雷数量：

    [NW] [N ] [NE]

    [W ] [ X] [E ]

    [SW] [S ] [SE]

count = 每个相邻位置是否为地雷（布尔累加）

该值直接决定了格子翻开后显示的数字或空格。

4.3 空格自动展开（Flood Fill）

翻开雷数为 0 的格子（空格）时，使用深度优先搜索（DFS）递归展开：

reveal_cell(r, c):

    if revealed[r][c] or 有旗子/问号标记 → 停止

    标记 (r, c) 为已翻开

    if board[r][c] > 0: 显示数字，停止

    if board[r][c] == 0: 对 8 个邻居递归调用 reveal_cell

点击一个空格即可让整个连通空白区域一次性展开，并在边界处停下显示数字。

4.4 Chord 双击展开

在已翻开的数字格上左键点击触发，是进阶玩家的高效操作：

do_chord(r, c):

    number = board[r][c]

    flag_count = 统计周围旗子数

    if flag_count != number:

        数字格金色闪烁 250ms（视觉反馈）

        return

    if 周围有未保护的地雷:

        游戏失败，直接展示所有雷（不翻开任何中间格）

        return

    翻开周围所有安全格子

原理：当周围插的旗子数恰好等于该格数字时，意味着剩余未翻开邻居必然是安全的。Chord 一键翻开它们，大幅提升操作效率。若旗子数与数字不匹配，数字格短暂变为金黄色作为反馈；若旗子标错且翻开的是地雷，直接判定失败。

4.5 胜利判定

遍历整个棋盘，确认没有非雷格子处于未翻开状态：

check_win():

    for each cell:

        if board[r][c] != -1 and not revealed[r][c]:

            return False

    return True

五、烟花庆祝动画

胜利后触发彩色粒子烟花：

1. Canvas 覆盖层 — 在窗口上方创建透明 tkinter Canvas 画布

2. 多轮爆发 — 分别在 100ms、600ms、1100ms 产生三轮随机位置爆发（4+3+3 次）

3. 粒子物理 — 每次爆发约 30 个粒子，具有随机方向初速度，受重力（+0.25/帧）和空气阻力（×0.94/帧）影响

4. 淡出效果 — 粒子生命周期内按比例缩小至消失

5. 自动清理 — 所有粒子消失后自动销毁 Canvas

六、难度配置

| 难度 | 棋盘大小 | 雷数 | 雷密度 |

| 初级 | 9×9 | 10 | ~12.3% |

| 中级 | 16×16 | 40 | ~15.6% |

| 高级 | 16×30 | 99 | ~20.6% |

七、运行方式

python minesweeper.py

环境要求：Python 3.x。tkinter 是 Python 标准库组件，无需额外安装依赖。
