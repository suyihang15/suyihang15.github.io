基于python的俄罗斯方块

注：这是本人基于pygame模块写的一个贪吃蛇，主要针对于新手练习。

项目地址：suyihang15/Tetris_game: 基于python的俄罗斯方块

下载地址：https://github.com/suyihang15/Tetris_game/releases/download/1.0.0/tetris_game.exe

俄罗斯方块（Tetris_game）

基于 Python 和 Pygame 实现的经典俄罗斯方块游戏，遵循现代俄罗斯方块标准规则。

功能特性

标准规则

7 种标准方块**：I、O、T、S、Z、J、L，每种方块有独立的颜色

SRS 旋转系统**（Super Rotation System）：每种方块拥有 4 个旋转状态

SRS 踢墙系统**（Wall Kick）：旋转时若位置被阻挡，自动尝试偏移位置，支持 I 方块和 JLSTZ 方块的两套踢墙表

高级机制

Ghost Piece（投影预览）**：显示方块落到底部时的预估位置

Lock Delay（锁定延迟）**：方块着地后有短暂时间可继续操作，避免误放

锁定移动上限**：着地后最多可移动/旋转 15 次，超过则强制锁定

DAS / ARR 按键重复**：按住左右键时，延迟 170ms 后以 50ms 间隔连续移动，手感流畅

Hard Drop（硬降）**：空格键一键落到底部，并获得双倍距离分数

Soft Drop（软降）**：按住下键加速下落，每下落一格 +1 分

游戏功能

分数与等级系统（每消除 10 行升一级，最高下落间隔 50ms）

等级加成消除分数（1 行~4 行：100/300/500/800 × 等级）

下一方块预览面板

暂停 / 重新开始功能

游戏结束画面

操作方式

| ← → | 左右移动方块 |

| ↑ | 旋转方块 |

| ↓ | 加速下落 |

| 空格 | 直接落到底部 |

| P | 暂停 / 继续 |

| R | 重新开始（游戏结束后） |

运行环境

Python 3.6+

Pygame

安装依赖后运行：

pip install pygame

python tetris.py

整体架构

项目为单文件实现，包含一个 `Tetris` 类，通过 Pygame 管理游戏循环、渲染和输入。

核心数据结构

棋盘 `board`******：20 行 × 10 列的二维数组，存储每个格子的占用状态

方块形状 `SHAPES`******：字典结构，每个方块名对应 4 个旋转状态（每个状态为 4 个坐标的列表）

踢墙表 `KICK_JLSTZ` / `KICK_I`******：SRS 标准定义的旋转偏移量，按旋转方向索引

方块颜色

| 方块 | 颜色 | 色值 |

|——|——|——|

| I | 青色 | (0, 240, 240) |

| O | 黄色 | (240, 240, 0) |

| T | 紫色 | (160, 0, 240) |

| S | 绿色 | (0, 240, 0) |

| Z | 红色 | (240, 0, 0) |

| J | 蓝色 | (0, 0, 240) |

| L | 橙色 | (240, 160, 0) |

渲染系统

棋盘格子 30px × 30px，右侧 200px 信息面板

窗口分辨率：500 × 600

方块高光效果：内层填充亮色、外层边框，模拟立体感

Ghost Piece 以半透明线条边框呈现

半透明遮罩覆盖暂停和游戏结束画面

游戏循环

每帧执行：

1. `handle_events()` — 处理键盘事件

2. `update(dt)` — 更新按键重复、方块下落计时、锁定延迟

3. `draw()` — 渲染棋盘、方块、Ghost Piece、UI 面板

运行帧率固定为 60 FPS。

文件说明

/

├── tetris.py    # 游戏主程序

└── README.md    # 本说明文档

网心云部署教程

注：用闲置的带宽跑pcdn赚钱本身属于灰色地带，运营商是打这种行为的，如果要部署，请自行考虑风险，所造成的为风险本人概不承担。

1、什么是pcdn

本质是一些内容提供的运营商为了降低服务器的压力，所需要的，当我们访问如网站这些时，我们实际是需要访问运营商的服务器，当我们访问后，在自己的电脑上会缓存一些数据，跑了PCDN，那么，当有你附近的人想访问相同的内容，就不用访问运营商的服务器了，可以在你的电脑上找到这些数据，这样就可以使其服务器的压力减小一点，但是，这会导致为你提供网络的运营商的压力激增，所以其是打击这种行为的，本质上是处于灰色地带。

2、部署compose

部署好后访问IP:18888

手机上下载一个网心云app绑定账号就可以了，他本身还需安装几天，如果想有收入请稳定挂几天，不然可能没有收益，

总结：跑PCDN本身还是有风险的，本文只是个教程，没有教唆的意向，风险请自行评估。

手机投屏到电脑（SCRCPY）

注：这主要原理还是是通过abd连接，其连接效果很流畅，可通过网络和usb连接

项目地址：Genymobile/scrcpy: Display and control your Android device

下载地址：https://github.com/Genymobile/scrcpy/releases/download/v4.0/scrcpy-win64-v4.0.zip

1、准备工作

（1）打开手机的开发者模式（一般狂点手机版本号八次）开启adb调试。

（2）下载并解压上面的文件

2、连接

（1）插好数据线可以直接点击解压的scrcpy.exe可执行文件就行了或者在下载文件的cmd里输入

.\scrcpy.exe−d.\scrcpy.exe -d

（2）网络连接，前提在同一局域网下，在命令行里输入

.\scrcpy.exe−−tcpip.\scrcpy.exe –tcpip

就是网络连接

总结：整体效果还不错，对于想做调试的人很不错。

CE修改器使用指南

注：本教程只适用于单机游戏，对于修改网络游戏造成的后果本人概不负责。

1、原理

当我们在打游戏时，我们的比如植物大战僵尸，当我们种植阳光时，我们的阳光值就会发生变化，CE修改器可以捕捉到这个变化的值然后，我们找出后对这个值进行修改，那么，就可以实现修改数字的目的。

2、风险

对于单机游戏一般风险是比较小的，但是不代表没有风险，因为一些厂家会有云端验证这种东西，就是其比如网游会上传到云端服务器，对其本地的存档进行一个验证，一旦检测到数据异常，就会有封号的风险，这也是一种比较常见的反作弊手段，但是，一般主要针对的是一些网游和要联网的单机游戏，这也是我们的存档可以进行云存档的原因，所以，请爱惜你自己的账号。

3、使用

（1）启动游戏和CE修改器，点击左上角的第一个搜索，找到游戏的进程，点击打开，之后，在数值这里填入你要修改的数值，后扫描，如果知道其是多少进制的就选择好，不知道就填全部。

这里比如我要改阳光，就填入150后进行首次扫描

可以看到左边出现了很多的数值，不知道是哪个，这时我们就要进行筛选了，通过种植植物，我们把阳光变成了50，此时，我们后台的数值也会变化，我们填入50，点击再次扫描，就找到了阳光对应的数值变化，

然后点击他，我们就能在下面的表格里找到这个进程。

之后，我们再点击下面的这个值，就会弹出一个修改框，只要修改里面的数值就能修改阳光了。

这里我随便改了个值确定以后，阳光就跟着变化了。

总结：本教程就是一个很简单的例子，CE修改器可以搞的事情还有很多，这只是一个大致的操作方法，但是请不要用于修改网游等其他的任何东西，毕竟账号还是很珍贵的，请爱惜自己的账号。

关于驱动

注：本文主要介绍什么是驱动及其作用

1、什么是驱动

当我们电脑上安装了显卡，网卡，声卡这些硬件以后，我们还安装了操作系统，我们的操作系统怎么去识别这些硬件呢，自然就是这些驱动了，驱动本身就是操作系统和硬件沟通的桥梁。

2、怎么打驱动

对于现在的操作系统，一般你在安装了以后，其在系统更新以后，会自动识别你电脑是的硬件（前提一般是大厂的），基本上不需要手动打驱动了，那么，在之前，安装驱动，一般是像驱动精灵，驱动大师，360驱动管家这些，你跑一次基本上就给你自动打上去了，还有一种就是自己去自己电脑的品牌官网上下载，然后手动下载对应的驱动，但是一般要下载好几个，基础的就是网卡，声卡，显卡驱动。

3、不打会有什么影响

现在其实影响很小了，在很早的时候，举一个例子，如果你电脑上不打网卡的驱动，那么，你的电脑上就算有WiFi的接收器，那么，你电脑上也连接不上WiFi，因为你的电脑上识别不了，其他的，还有比如游戏启动不了，组件缺失等下一系列问题。

4、对于现在

基本上我们现在不需要担心这些问题了，很多电脑现在出厂自带驱动了。

总结：对于现在基本不要担心了，只要不重装系统基本上就不会有打驱动的问题，可以说现在的操作系统已经方便了很多了。
