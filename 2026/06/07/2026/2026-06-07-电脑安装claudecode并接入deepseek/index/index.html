电脑安装claudecode并接入deepseek

注：本教程无需配置任何特殊网络环境，可绕开登录

1、环境准备

node.js

git

cc switch

deekseek申请API记得要有一定的额度。

2、检查环境并安装

node版本检查：node -v
npm版本检查：npm -v
npm国内镜像：npm config set registry https://registry.npmmirror.com/
git版本检查：git -v

关闭Windows安全策略：Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

ClaudeCode安装命令：npm install -g @anthropic-ai/claude-code
ClaudeCode版本检查：claude –version
启动ClaudeCode：claude

安装好以后配置.claude.json文件，要先在这里显示出隐藏的文件才能找到.claude.json文件用记事本打开。

打开以后，记得切换为英文模式，

上一个字段尾部加英文逗号后加入：”hasCompletedOnboarding”: true

记得写在}前面。

打开cc switch，添加deepseek模型，输入你上面申请的api的key后保存。

打开cmd输入claude启动他，再输入/model选择好配置的model就可以直接用了

效果展示

整体来说还是很不错的，当然你也可以配置其他的model，但是有的需要一些魔法环境，或者用ai中转站（当然个人不建议，因为ai中转站挂羊头卖狗肉的情况还是不少的，而且其本身是处于一个灰色产业），就在cc switch里配置就行，但是，我个人觉得deepseek v4是本人目前来说不用配置魔法环境，最好用的，但是，缺点个人用下来其图像识别能力是比较差的，写代码处理问题这些确实是不错的，很聪明。

总结：大致就这样，你后面还可以自行配置其他的如skills这些，还有注意key的消耗。
