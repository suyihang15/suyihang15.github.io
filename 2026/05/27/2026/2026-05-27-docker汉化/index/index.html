Docker汉化

注：本文章主要介绍第三方的汉化版

项目地址：asxez/DockerDesktop-CN: Docker汉化 Docker中文版 Docker汉化包 DockerDesktop汉化 Docker Windows Docker MAC

1、前期准备

（1）下载好docker（记得查看安装的版本）

（2）下载上面的汉化包解压后复制app.asar

2、开始汉化（注意弄之前请退出并做好汉化版的备份，不然可能会出现一些问题）

打开应用所在目录

C:\Program Files\Docker\Docker\frontend\resources

默认安装在c盘就在这个位置就可以找到

然后替换掉这里的文件，重启就可以看到汉化后的docker了，但是注意要下载对应的版本，不然可能会闪退打不开等问题。
