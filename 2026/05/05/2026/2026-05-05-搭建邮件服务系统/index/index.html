搭建邮件服务系统

注：对于一些隐私及其看中的公司，可以直接搭建一套完整的邮箱系统然后用于使用

项目地址：Billionmail/BillionMail：BillionMail为您提供开源的邮件服务器、通讯和电子邮件营销——完全自托管，开发者友好，且免月费。加入Discord：https://discord.gg/asfXzBUhZr

1、作用

就和像qq邮箱和163邮箱一样，但是如果想要公开使用，请进行备案，否则发到其他邮箱会被认为是垃圾信息然后被拦截。

2、部署

在终端执行

cd /opt && git clone https://github.com/aaPanel/BillionMail && cd BillionMail && bash install.sh

就行

配置好域名解析和dns记录

3、效果展示

后面就可以了。

总结：对于一些经常用邮箱的人这个肯定可以对你有一定的帮助。
