PDF处理工具（Stirling PDF）

注：对于经常办公的人员来说，文件的处理是很麻烦的这个项目就是帮助你解决这一痛点的。

项目地址：Stirling-Tools/Stirling-PDF: #1 PDF Application on GitHub that lets you edit PDFs on any device anywhere

体验地址：

1、准备

安装docker

注：如果你只是自己用就部署到本地就行，如果要对外服务还是要购买云服务器。

2、作用

Stirling PDF 是一个强大的开源 PDF 编辑平台，可以作为个人桌面应用运行，在浏览器中运行，或者用私有 API 部署到自己的服务器上。编辑、签署、编辑、编辑、转换和自动化 PDF 文件，无需将文档发送给外部服务。

2、部署

docker compose部署命令

version: “3.8”

services:
stirling-pdf:
image: frooodle/s-pdf:latest
container_name: stirling-pdf
restart: always
ports:
- “8080:8080” # 宿主机端口:容器端口，前面的 8080 可根据需要改成别的
volumes:
- ./config:/configs
- ./files:/files
environment:
- TZ=Asia/Shanghai

（1）在服务器上新建一个文件夹

mkdir -p ~/stirling-pdf

cd ~/stirling-pdf
 
（2）新建  docker-compose.yml  文件，把上面的内容复制进去保存

nano docker-compose.yml
 
（3）启动服务

sudo docker-compose up -d
 
（4）查看是否启动成功

sudo docker-compose ps  

然后打开：http://你的ip地址:8080

对，docker就是这么简单。
