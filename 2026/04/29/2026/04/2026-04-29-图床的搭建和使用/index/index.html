图床的搭建和使用

注：我确实觉得这个很适合那些刚开始想网站小白要展示一些照片，但是又觉得存储不太方便的人。

1、什么是图床

按照我个人的理解，他就是一个可以帮我们存储图片的软件，当我们想要去使用时，只需要调用它的URL（就是他的一个专属地址）就行。

2、搭建图床（空蓝图床其本身是开源的）

首先你要有一台云服务器（建议香港的，如果是国内的记得备案）

（1）安装宝塔面板

if [ -f /usr/bin/curl ];then curl -sSO https://download.bt.cn/install/install\_panel.sh;else wget -O install_panel.sh https://download.bt.cn/install/install\_panel.sh;fi;bash install_panel.sh ed8484bec

（2）下载这个压缩包

https://github.com/lsky-org/lsky-pro/releases/download/2.1/lsky-pro-2.1.zip

（3）添加站点

安装好php8.1，其他版本可能会出错，我个人搞得是这个。

创建站点，记得要添加my sql数据库，用于做存储，不然他就是一个静态文件，并填好域名后面要解析。

打开文件目录并上传之前下载的安装包解压

设置网站的运行目录为public

设置伪静态

代码

location / {
if (!-e $request_filename) {
rewrite ^(.*)$ /index.php?s=$1 last; break;
}
}

保存好了，然后就访问解析好的域名就行了

如果有上面的错误，根据上面要的，安装对应的插件

注意有部分可能被禁用了，设置一下就行

一个一个设置好了就可以开始了

这里填入你前面设置的数据库名称和密码，其他的不要动，数据库类型选择你前面安装的版本看一下就行。

登录以后上传就行

上传后你会得到一个URL后面直接调用就行，很方便的

这个图床的其本身是开源的，网络上也有不少基于他搭建的免费图床，你可以自己搭建，也可用别人搭建好的，总之是很方便的。

一个简单的调用方法就是

< img src=”图片的URL”>

我个人觉得是很方便的

总结：如果你的网站有挂图片的需求这会是一个不错的选择，但是切记，不可用来存储任何暴力色情的图片，其照片的URL是任何人都可以用的，注意不要上传太过私密的照片。
